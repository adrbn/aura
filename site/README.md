# Aura site

The website lives in its own public repository, [adrbn/aura-site](https://github.com/adrbn/aura-site):
the landing page and the privacy policy, plain HTML with no build step.

- **Landing page:** <https://aura.adrbn.dev> (Vercel, from `main`)
- **Privacy policy:** <https://adrbn.github.io/aura-site/privacy.html> (GitHub Pages, from `main`) —
  the URL registered in App Store Connect. Keep that path working, or change App Store Connect first.

`privacy.html` here is a copy of the published page, kept in step with [`PRIVACY.md`](../PRIVACY.md).
When the policy changes, edit `PRIVACY.md`, then the page in `aura-site`, then copy it back here.
